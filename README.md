この手順書では、操作する場所を以下の3つにハッキリ分けて指示します。
**手順の見出しに必ずどの場所かを書いてあるので、迷ったら見出しを見てください。**

| ラベル | どこ？ | どう操作する？ |
|--------|--------|---------------|
| **【ターミナル】** | Macの「ターミナル.app」（黒い画面） | コマンドをコピペしてEnter |

# PART 0: Mac基本環境を整える（ターミナル中心 / 30分）

> **ここで使うのは「ターミナル」と「ブラウザ」のみ。**
> Claude Codeはまだ入っていないので、自分でコマンドをコピペします。
> どれもMacを使う上での「基礎ツール」で、一度入れれば二度と触りません。

## 0-1. ターミナル.appを開く（前述）

## 0-2. 【ターミナル】Homebrew をインストール

> Homebrew = Macで便利なツールをまとめてインストールできる仕組み。これがないと後続が進みません。

以下を **1行で** コピーしてターミナルに貼り付け、Enter：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

- 途中でMacのパスワードを求められる → ログイン時のパスワードを入力（画面に表示されないが入力されています）
- 数分かかる
- 最後に画面に「**Next steps:**」と表示され、`echo` で始まる2行のコマンドが出る → **その2行を1行ずつコピペして実行**（これでパスが通る）

**確認：**
```bash
brew --version
```
`Homebrew x.x.x` と返ってくればOK。

## 0-3. 【ターミナル】Git をインストール

> Git = ファイルの変更履歴を残す仕組み。後でGitHubと連携します。

```bash
brew install git
```

確認：
```bash
git --version
```

## 0-4. 【ターミナル】Git の初期設定（必須）

`{あなたの名前}` と `{あなたのメール}` を自分のものに書き換えてから実行：

```bash
git config --global user.name "{あなたの名前}"
git config --global user.email "{あなたのメール}"
git config --global init.defaultBranch main
```

例：
```bash
git config --global user.name "山田太郎"
git config --global user.email "yamada@example.com"
```

## 0-5. 【ターミナル】Node.js をインストール

> Node.js = Claude Code CLI と各種MCPサーバーが動くために必要。

```bash
brew install node
```

確認：
```bash
node --version
npm --version
```
両方バージョンが表示されればOK。

## 0-6. 【ブラウザ＋アプリ】Google Drive for Desktop をインストール

> このシステムのフォルダはGoogle Drive内に置きます。同期しないと作業できません。

1. ブラウザで [google.com/drive/download](https://www.google.com/drive/download/) を開く
2. 「Mac用」をクリックしてダウンロード
3. `.dmg` ファイルを開いて、アイコンを「Applications」フォルダにドラッグ
4. `アプリケーション` → Google Drive を起動
5. Googleアカウントでログイン
6. 同期設定で **「マイドライブをこのパソコンと同期」** を有効化
7. Finderで `~/Library/CloudStorage/GoogleDrive-{あなたのメール}/マイドライブ/` が見えればOK

# PART 1: Aqua Voice（音声入力）をインストール（ブラウザ＋アプリ / 15分）

> 早めに入れておくと、この後Claude Codeに長文を渡すときに口頭でしゃべるだけで済みます。タイピング負担が激減します。

## 1-1. 【ブラウザ】aquavoice.com からダウンロード

1. [aquavoice.com](https://aquavoice.com/) を開く
2. 「Download for Mac」をクリック → `.dmg` を保存

## 1-2. 【アプリ】インストール＆権限付与

1. ダウンロードした `.dmg` を開く
2. Aqua Voice のアイコンを Applications フォルダにドラッグ
3. アプリを起動
4. **マイクへのアクセス許可** → 「許可」
5. **アクセシビリティ権限** → `システム設定 → プライバシーとセキュリティ → アクセシビリティ` でAqua Voiceをオン

## 1-3. 【アプリ】初回設定

1. Google or メールでアカウント作成
2. プラン選択：
   - **Starter（無料／月1,000単語）** — まず日本語精度を試したい人向け
   - **Pro（$8/月／無制限）** — 業務で毎日使うなら必須
3. キーボードショートカットを確認（デフォルト「Fnキー長押し」or「スペースキー長押し」）

## 1-4. 【アプリ】カスタム辞書に固有名詞を登録

設定 → 辞書（Dictionary）で以下を入れる：

| カテゴリ | 例 |
|---------|----|
| 自社・関連事業 | 自社名、Greeth、fureru |
| クライアント名 | 取引先の正式名称 |
| 専門用語 | ふるさと納税、おがこ、リサイクル査定 |
| よく使う英単語 | Claude、MCP、CLAUDE.md、Sonnet |

## 1-5. 注意事項
- 日本語UIは公式に明記なし。日本語精度は無料版で先に確認推奨
- **機密情報（顧客名・契約金額・口座番号など）は音声入力しない**（音声がサーバー送信されるため）

# PART 2: Claude Code をセットアップする（ブラウザ＋アプリ / 30分）

## 2-1. 【ブラウザ】Anthropicアカウントを作る

1. [claude.ai](https://claude.ai) を開く
2. 「Googleで続ける」をクリック
3. メール認証完了

## 2-2. 【ブラウザ】Proプランを契約

> **無料プランではClaude Codeは使えません。** Pro以上が必須。

| プラン | 価格 | 用途 |
|--------|------|------|
| Free | 無料 | ❌ Claude Code不可 |
| **Pro** | $20/月 | ✅ 初心者はこれ |
| Max | $100/月〜 | 上級者・並列実行向け |

## 2-3. 【ブラウザ＋アプリ】Claude Codeデスクトップアプリをインストール

1. [claude.com/download](https://claude.com/download) を開く
2. 「Mac」ボタンをクリック → `.dmg` ダウンロード
3. `.dmg` を開き、Claudeアイコンを Applications フォルダにドラッグ
4. `アプリケーション` から Claude を起動
5. アプリ画面で「コード」を選択

## 2-4. 【アプリ】初回認証

1. アプリ起動でブラウザが自動で開く
2. Anthropicアカウントでログイン
3. **「Log in with your subscription account」を必ず選ぶ**
4. 「Allow（許可）」をクリック

> **超重要**: 「Use an API key」を選ぶと **従量課金で数万円の請求** が来る可能性。絶対に選ばない。

## 2-5. 【アプリ】最初の設定3つ

### (1) パーミッションモード（左下メニュー）→「プランモード」
変更前にAIが計画を見せてくれるので安全。

### (2) モデル選択（右上）
- **Opus** = 戦略・設計・重要判断
- **Sonnet** = 定型作業・実装・編集

### (3) フォルダを選択（左下）
**ここが重要。** Claude Codeが触れるフォルダを指定します。
**Google Drive内のシステムフォルダ** を指定してください：

```
~/Library/CloudStorage/GoogleDrive-{あなたのメール}/マイドライブ/00_Claude Code
```

> このフォルダがまだ無い人は、Finderで `マイドライブ` の中に `00_Claude Code` という空フォルダを作成してから指定。

## 2-6. 【Claude Codeに頼む】動作確認

Claude Codeアプリの入力欄（画面下部）に、以下をコピペしてEnter（**Aqua Voiceで音声入力もOK**）：

```
こんにちは。あなたが今見えているフォルダのパスと、その中のファイル一覧を教えてください。
```

→ フォルダパスとファイル一覧が返ってくればOK。

## 2-7. 覚えるコマンドは3つだけ

入力欄で「/」を打つとコマンド一覧が出ます。

| コマンド | いつ使う |
|---------|---------|
| `/clear` | **新しい仕事を始める前** |
| `/compact` | 会話が長くて精度低下時 |
| `/exit` | 作業終了時 |

### 便利キー
| 操作 | 効果 |
|------|------|
| `Shift + Enter` | 改行（送信せずに続きを書く） |
| `Esc` | AIの作業を中断 |

## 2-8. 【重要】Claude Codeへの「頼み方」の基本

> この手順書ではこの後、何度も **「Claude Codeに頼む」** が出てきます。
> 頼み方の質で結果が大きく変わるので、ここで型を覚えておきましょう。

### 良い頼み方の4要素

| 要素 | 例 |
|------|-----|
| 1. 何をするか | 「企画書ドラフトを作って」 |
| 2. 背景・条件 | 「クライアントは食品メーカー／予算300万／納期3週間」 |
| 3. どこに保存 | 「03_creative/clients/A社/ に proposal_v1.md として」 |
| 4. 完了確認 | 「できたら見せて／ファイル一覧を出して」 |

### 悪い例 vs 良い例

❌ **悪い例**
```
企画書作って
```

✅ **良い例**
```
A株式会社の新商品プロモーションの企画書ドラフトを作ってください。
- 業種：食品メーカー
- ターゲット：30〜40代の働く女性
- 予算：300万円
- 納期：3週間後
- 03_creative/clients/A社/ に proposal_v1.md として保存
- 完了したら、要点だけ見せて修正させてください
```

### 困ったときの「魔法のフレーズ」

| 状況 | コピペして使えるフレーズ |
|------|------------------------|
| 何を頼めばいいかわからない | 「[やりたいこと]をするには、どう頼めばいい？」 |
| AIの回答が的外れ | 「ちょっと違う。私が欲しいのは◯◯」 |
| 結果が長すぎる | 「もっと簡潔に、3行で」 |
| 結果が短すぎる | 「もう少し具体的に、各項目に例を入れて」 |
| 途中で違うとわかった | Escキーで中断 → 「最初からやり直そう」 |
| 全く動かなくなった | `/clear` で会話をリセット |
| 何度言っても伝わらない | 「ultrathink で考えて、もう一度やり直して」 |
| やったことを記録したい | 「今日やった作業を、DAILY.mdに追記して」 |
| ファイルを失いそうで怖い | 「実行前に、何を変更するか先に教えて」 |

### よく使う「お決まりフレーズ」

```
このフォルダの中の構造を見せて
```
```
[ファイル名] の中身を見せて
```
```
[ファイル名] を、以下のように修正して：[修正内容]
```
```
今日やった作業の要約を作って、DAILY.mdに追記して
```
```
このスクリーンショットのエラーを解決する手順を教えて
```

# PART 3: Google に接続する（ブラウザ＋Claude Codeに頼む / 45分）

> ここから先は **Claude Codeに頼む** 場面が増えます。
> 各ステップで「【ブラウザ】」or「【Claude Codeに頼む】」のラベルを見て、どこで作業するか判断してください。

## 3-1. 【ブラウザ】Google Cloud プロジェクトを作る

1. [console.cloud.google.com](https://console.cloud.google.com/) を開く（Googleでログイン）
2. 利用規約に同意
3. 画面上部のプロジェクト選択 → 「**新しいプロジェクト**」
4. 名前：`claude-mcp-personal`（何でもOK）→ 「作成」
5. 作成したプロジェクトを **選択中** にする（画面上部で表示確認）

## 3-2. 【ブラウザ】5つのAPIを有効化

左メニュー → 「APIとサービス」 → 「**ライブラリ**」

以下5つを **1つずつ検索→「有効にする」** の繰り返し：

- Gmail API
- Google Calendar API
- Google Drive API
- Google Docs API
- Google Sheets API

## 3-3. 【ブラウザ】OAuth同意画面を設定

左メニュー → 「APIとサービス」 → 「**OAuth同意画面**」

1. **User Type**：`外部` → 作成
2. **アプリ情報**：
   - アプリ名：`claude-mcp`
   - ユーザーサポートメール：自分のGmail
   - デベロッパー連絡先：自分のGmail
3. 「保存して次へ」
4. **スコープ**：何も追加せず「保存して次へ」
5. **テストユーザー**：「ADD USERS」→ 自分のGmailを追加
6. 「保存して次へ」→「ダッシュボードに戻る」

## 3-4. 【ブラウザ】OAuthクライアントIDを作る

左メニュー → 「APIとサービス」 → 「**認証情報**」

1. 「+ 認証情報を作成」 → 「**OAuth クライアント ID**」
2. アプリケーションの種類：**デスクトップアプリ**
3. 名前：`claude-mcp-client`
4. 作成 → 「**JSON をダウンロード**」
5. ダウンロードファイル（`client_secret_xxx.json`）の場所をFinderで確認

## 3-5. 【Claude Codeに頼む】credentials.jsonを安全な場所に配置

Claude Codeアプリの入力欄に以下をコピペ：

```
ダウンロードフォルダにある client_secret_で始まるJSONファイルを、
~/.config/google-mcp/credentials.json にリネーム＆移動してください。

手順：
1. ~/.config/google-mcp/ フォルダがなければ作成
2. ダウンロードフォルダから該当ファイルを移動
3. ファイル名を credentials.json に変更
4. 完了後、配置先のファイル一覧を見せてください

なお、このファイルは絶対にGitHubに上げてはいけません。後で .gitignore に登録します。
```

## 3-6. 【Claude Codeに頼む】.mcp.json を作る

```
このフォルダの直下に .mcp.json を作成してください。

中身は以下のとおり。
{
  "mcpServers": {
    "google-workspace": {
      "command": "uvx",
      "args": ["workspace-mcp"],
      "env": {
        "GOOGLE_OAUTH_CLIENT_SECRETS_FILE": "/Users/[私のユーザー名]/.config/google-mcp/credentials.json"
      }
    }
  }
}

[私のユーザー名] の部分は、私のMacの実際のユーザー名に置き換えてください。
（whoami コマンドで確認できます）

作成後、ファイルの中身を見せて確認させてください。
```

## 3-7. 【アプリ】Claude Codeを再起動

Claude Code を一度終了して、もう一度起動。（.mcp.jsonの読み込みのため）

## 3-8. 【Claude Codeに頼む】Google認証を開始

```
Googleの認証を開始してください。
mcp__google-workspace__start_google_auth を実行して、ブラウザでログイン画面を開いてください。
```

→ ブラウザが開く
- 自分のGoogleアカウントを選択
- 「このアプリは確認されていません」と出る → 「**詳細**」→「**claude-mcp に移動**」→「**許可**」
- 「認証完了」が表示されればOK

## 3-9. 【Claude Codeに頼む】動作確認

```
今日のGoogleカレンダーの予定を教えてください。
```

→ 予定が返ってくれば成功。

# PART 9: 安全ルール・トラブル対処・全体チェックリスト

## 9-1. 安全に使う5つのルール

1. **「Use an API key」を選ばない** — 必ずサブスクリプションログイン
2. **「許可をバイパス」モードは使わない** — AI暴走時にファイル破壊リスク
3. **作業フォルダ以外を触らせない** — フォルダ選択を毎回確認
4. **機密情報**：
   - 顧客名・契約金額・口座番号などは Aqua Voiceに音声入力しない
   - `credentials.json` `.env` はGitHubに上げない（.gitignore必須）
5. **同じファイルを複数のClaudeで同時編集しない** — 上書き事故防止

## 9-2. 困ったときの対処

| 症状 | 原因 | 対処 |
|------|------|------|
| `command not found: brew` | Homebrew PATH未設定 | インストール時の「Next steps」を再実行 |
| `git: command not found` | Gitが入ってない | `brew install git` |
| Claude Codeアプリが起動しない | ファイル破損 | 再ダウンロード |
| ログインできない | Freeプラン | Proにアップグレード |
| 動作がおかしい・指示を間違える | コンテキスト溢れ | `/clear` で初期化 |
| Aqua Voiceがマイクを認識しない | 権限未付与 | `システム設定 → プライバシー → マイク` |
| 日本語の認識精度が悪い | 辞書未登録 | カスタム辞書に固有名詞追加 |
| Google「アプリが確認されていません」 | テストユーザー扱い | 「詳細→続行」でOK |
| Googleカレンダー取得でエラー | API未有効化 | 5つのAPI全て有効化を再確認 |
| `redirect_uri_mismatch` | OAuthクライアント種別違い | 「デスクトップアプリ」で再作成 |
| `gh: not authenticated` | gh認証切れ | Claude Codeに「`gh auth login`をもう一度実行して」 |
| GitHubのissueに機密情報を書いた | 抽象化忘れ | すぐ削除→「自治体A」など匿名化で再投稿 |

> **困ったら、画面のスクリーンショットをClaude Codeに貼って「これ解決して」が一番速い。**
